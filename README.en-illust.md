## Visual system

The README now uses one recurring visual motif: a small black worker that sorts material and hands the useful part to a human.

- **Worker:** round black head, simple white face, short legs, oversized dark coat, small orange satchel.
- **Role:** active operator—sorting, carrying, or stopping an extra action. Never a corner sticker or passive mascot.
- **Composition:** noisy input on the left, one physical mechanism in the middle, human reader or boundary on the right.
- **Line and palette:** loose black hand-drawn lines on white, with sparse orange and blue accents; red appears only for a blocked or out-of-scope action.
- **Metaphors:** sieve, tray, table, paper, rope, and lever. No dashboards, interface icons, or flowchart boxes.
- **Text:** no words inside the raster assets. Small bullets and horizontal marks make documents read as organized without adding readable prose. README alt text and captions carry the meaning.

The worker is an original project illustration motif, not a named character or a runtime mascot. It should remain visually distinct from upstream or famous characters and should keep performing the core action.
